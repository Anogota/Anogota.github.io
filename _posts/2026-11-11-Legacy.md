### Gaining Accesss

```terminal
0  exploit/windows/smb/smb_relay    2001-03-31       excellent  Yes    MS08-068 Microsoft Windows SMB Relay Code Execution
```
But it wasn't this, this module will relay SMB authentitacion requests to anothere host, gaining access to an authenticated SMB session if successfuly. But then i found this MS08-067, and it was that. I also search it in metasploit, exploit/windows/smb/ms08_067_netapi
And to obtain a NT AUTHORITY\ SYSTEM was from downhill.
This module exploits a parsing flaw in the path cannonicalization code of NetAPI32.dll trough the Server Service. This module is capable of bypassing NX on some operating system and service packs. The correct target must be used to prevent the Server Service (along with a dozen otheres in the same processs) from cashing.
