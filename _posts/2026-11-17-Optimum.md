### Exploit analysis
CVE-2014-6287
The findMacroMarker function in parserLib.pas in Rejetto HTTP File Server (aka HFS or HTTP Fileserver) 2.3x before 2.3c allows remote attackers to execute arbitrary programs via a %00 sequence in a search action, due to a poor regex. It won't handle a null byte, allowing an attacker to inject code.

### Sumary
The box was easy. The main problem was outdated software, which made it vulnerable to a publicly known exploit. For initial access, I used the exploit/... module in Metasploit. All I had to do was set the required options, such as RHOSTS and LHOST. For privilege escalation, I used another automated module, which was even simpler than the first step.
Although Metasploit made this box very quick, I want to practice doing it manually to better understand what happens behind the scenes. To prevent this, administrators should keep software up to date and regularly patch known vulnerabilities.
